# Elysia

Пример веб-сервера на [Elysia](https://elysiajs.com) и [Bun](https://bun.sh), который можно
развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack видит в `package.json` поле `packageManager` с Bun: ставит Bun этой версии и зависимости и
запускает `bun run start`. Приложение слушает порт из переменной окружения `PORT` — её передаёт
платформа, — а без неё `3000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# зависимости
bun install

# запуск в режиме разработки
bun run dev

# запуск как на платформе
bun run start
```

Приложение откроется на `http://localhost:3000`. Нужен Bun 1.4 или новее.
